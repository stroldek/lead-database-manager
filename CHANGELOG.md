# CHANGELOG

## 0.1.2 — 2026-11-22

Тестовый шаг: живое подключение аккаунта, мониторинг, тестовая база, Excel.

### Добавлено
- Вход в аккаунт Telegram по QR-коду и вручную (номер → код → пароль 2FA), обновление QR на странице, отмена входа, выход из аккаунта.
- Telegram-движок на Durable Object: сессия переживает перезапуск, хранится зашифрованной (AES-GCM, ключ из `APP_SECRET`) в D1; при отозванной сессии мониторинг останавливается и показывается причина.
- Мониторинг групп, супергрупп и комментариев каналов (через группу обсуждения); первая проверка запоминает «точку отсчёта», далее читаются только новые сообщения; пагинация по 100 сообщений; пауза при FLOOD_WAIT; сбой одного чата не останавливает остальные.
- Тестовая база лидов: один человек = одна запись, счётчик совпавших сообщений, защита от повторной обработки того же сообщения, поиск (регистронезависимый для кириллицы и «ё»), очистка с подтверждением.
- Выгрузка в Excel: Имя · Ник · Номер телефона (нет → `Nope`) · Источник · Дата добавления (Киев) · Текст сообщения-триггера; файл собирается в браузере постранично.
- Кнопка «Диагностика» по слоям: настройки сервера, база, библиотека Telegram, сеть, рукопожатие MTProto.
- Вход в панель по `ADMIN_TOKEN`, ограничение неверных попыток, весь `/api/*` закрыт, кроме `/api/health` и webhook бота.
- Миграция `0002_live_telegram_test.sql`.
- Тесты: 33 unit/API-теста, 12 шагов браузерной проверки (`tests/ui_e2e.py`).

### Исправлено
- Поиск по базе не находил кириллицу в другом регистре («олег» ≠ «Олег») — добавлено нормализованное поле `search_norm` и регрессионный тест.

### Ограничения
- Реальная работа GramJS внутри Cloudflare Workers не проверялась (нет сети в среде разработки): подтверждается кнопкой «Диагностика» после публикации.
- Программа только читает чаты; отправка сообщений и действия с профилем — позже. Удаление аккаунта не предусмотрено.
- Бот этапа 1 (webhook, согласие) сохранён без изменений и необязателен.

## 0.1.1 — 2026-11-12

### Исправлено в поставке
- Добавлен `START_HERE.html` для запуска предпросмотра двойным щелчком.
- Исправлены пути CSS/JS для открытия проекта по `file://`.

## 0.1.0 — 2026-11-12

### Добавлено
- Документирована архитектура Workers + D1 + Static Assets.
- Подготовлена ER-модель основной базы и будущих модулей.
- Реализован Cloudflare Worker API для health-check и Telegram webhook.
- Реализована регистрация webhook через защищённый endpoint.
- Добавлено подтверждение согласия через inline-кнопку.
- Добавлена команда `/stop` для отзыва согласия.
- Добавлена защита от повторной обработки Telegram update через таблицу `telegram_updates`.
- Добавлен базовый тёмный интерфейс технического контроля.
- Добавлены SQL- и unit-тесты.

### Ограничения
- Полный модуль управления лидами и сегментами относится к этапам 3–6.
- Импорт/экспорт относится к этапу 7.
- Сбор из внешних Telegram-источников сверх стандартных bot updates не реализован; проверка доступности описана в документации.
- Полноценная web-auth и управление ролями относятся к этапу 10.
