## B. Проверка на вашем Cloudflare (только вы можете выполнить)

| № | Действие | Ожидаемый результат |
|---|---|---|
| 1 | Открыть адрес Worker, ввести `ADMIN_TOKEN` | Открывается «Обзор», база D1 — «Подключена» |
| 2 | Неверный ключ | «Ключ не принят», панель закрыта |
| 3 | Аккаунт Telegram → «Запустить проверку» | Все пункты зелёные. **Красный пункт — главный результат шага**: пришлите его название и текст |
| 4 | Сохранить `api_id` / `api_hash` | «Сохранены» |
| 5 | «Показать QR-код», отсканировать в Telegram | Карточка аккаунта с вашим именем |
| 6 | (если включена 2FA) | Запрос пароля, неверный пароль — понятная ошибка, верный — вход |
| 7 | «Выйти из аккаунта» → «Войти вручную» | Номер → код → вход |
| 8 | Мониторинг → выбрать группу и канал с комментариями | Оба в списке источников; канал без комментариев отклонён с пояснением |
| 9 | «Любое сообщение» + «Проверить» | Прочитано N сообщений, найдены новые пользователи |
| 10 | Тестовая база | Имя, ник, источник, дата, текст; без телефона — `Nope` |
| 11 | «Скачать Excel» | Файл открывается в Excel, 6 колонок, кириллица корректна |
| 12 | Запустить мониторинг, написать в чат с ключевым словом | Через интервал проверки автор появляется в базе |
| 13 | Повторить «Проверить» | Новых дубликатов нет |
