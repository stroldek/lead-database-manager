    Telegram-бот из этапа 1 (необязательно)

    Бот принимает лидов, которые сами написали ему и дали согласие. Для проверки аккаунта и мониторинга он не нужен.

    ШАГ 1

    Ключи приложения Telegram

    —

    Telegram требует, чтобы программа, входящая в аккаунт, имела свои ключи. Они бесплатные: откройте my.telegram.org → войдите по номеру → API development tools → создайте приложение (название любое) → скопируйте api_id и api_hash.

    Ключи хранятся на сервере в зашифрованном виде и никогда не возвращаются в браузер.
    ШАГ 2

    Подключение аккаунта

    —
    ЕСЛИ ЧТО-ТО НЕ РАБОТАЕТ

    Диагностика соединения

    Проверяет по очереди: настройки сервера, базу, загрузку библиотеки Telegram, сетевое соединение и шифрованное рукопожатие. Каждый шаг показывает, где именно остановка.

      i

      Подключённый аккаунт — это обычный вход «как с ещё одного устройства». Для тестов лучше использовать отдельный или запасной аккаунт: Telegram может ограничить аккаунт, если он ведёт себя как робот (частые запросы, массовые действия). Текущая версия только читает выбранные чаты и ничего не пишет и не меняет в аккаунте.

      ШАГ 3

      Что искать

      Поиск без учёта регистра и буквы «ё»; ищется часть слова («куплю» найдёт «куплю оптом»).
      ШАГ 4

      Запуск

      Проверить прямо сейчас

      Читает последние сообщения выбранных чатов и сразу применяет условия — удобно, чтобы убедиться, что всё работает, не дожидаясь новых сообщений.

      ИСТОЧНИКИ

      Какие чаты слушаем

      Для канала читаются комментарии — они живут в привязанной группе обсуждения. Сообщения самого канала лидов не дают: их публикует канал.
